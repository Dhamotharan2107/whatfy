How It Works

From QR scan to autonomous AI in 4 steps.

No code. No developers. Just scan, configure, and your WhatsApp starts replying with business context.

Step 01
Connect WhatsApp
Scan the QR code with WhatsApp → Linked Devices, or use phone number pairing. WhatsMeow handles the multi-device protocol. You're live in minutes.
Step 02
Enable Agents
Toggle Shop, Invoice, Health, and Appointment agents. Add your inventory, shop profile, patients, or schedules. The AI reads only what you enable.
Step 03
AI Takes Over
Incoming messages hit FastAPI, which builds a context prompt from your live data, calls GLM-4.7 Flash, and replies via Go. Autonomous appointment booking included.
Step 04
Scale with MCP
Connect Claude, Cursor, or any MCP-compatible AI. Run bulk campaigns with Excel upload. Use the full REST API. Your WhatsApp is now a platform.
🔌 Model Context Protocol

Connect any MCP-compatible AI to your WhatsApp.

Whatfy runs a standalone MCP server with OAuth authentication, Excel batch processing, and rate limiting. Claude, Cursor, Copilot, or your custom agent can read contacts, send messages, and run campaigns — all through the open Model Context Protocol.

✓
OAuth-secured server — client credentials flow with per-user API keys. 10 req/min, burst-protected, 429-safe.
✓
Excel batch upload — import up to 5,000 contacts per file. Send personalized template campaigns to 1,000+ numbers at once.
✓
Universal AI access — any MCP-compatible assistant can query inventory, book appointments, and send WhatsApp messages.
